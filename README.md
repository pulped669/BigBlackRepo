# Big Black Coin ($BBC)

Memecoin site for **Big Black Coin** — ticker `$BBC`, culturally tied to BlackBerry `$BB` on Robinhood Chain.

White void. Black coin. BlackBerry mark on the front, `$BBC` on the back. It flips.

## Run

```bash
npm install
npm run dev
```
